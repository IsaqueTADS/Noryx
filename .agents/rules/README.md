# Regras do projeto Noryx

Regras locais obrigatórias para agentes que trabalham neste aplicativo. Estas são instruções do projeto; não dependem de um editor carregar automaticamente esta pasta. O `AGENTS.md` na raiz exige a leitura destes arquivos.

1. `noryx-decisoes.md`: cópia integral do documento de produto fornecido pelo usuário.
2. `produto-e-escopo.md`: aplicação das decisões e registro do estado real desta fundação.
3. `typescript.md`: tipagem, validação e tratamento de erros.
4. `react-native.md`: componentes, acessibilidade, desempenho e privacidade.
5. `expo-router.md`: Expo, rotas, módulos nativos e development builds.
6. `nativewind.md`: estilos e design tokens.
7. `git.md`: Conventional Commits e commits pequenos por funcionalidade.

As instruções do usuário na conversa têm precedência sobre estas regras. Regras técnicas não ampliam o escopo de funcionalidades solicitado. Ao mudar SDK ou bibliotecas, revise as fontes oficiais e atualize as regras afetadas. Data da pesquisa: 09/11/2026.
